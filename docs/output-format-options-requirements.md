# 出力形式オプション 追加要件定義書

## 1. 目的

Excelマクロのドローオプション設定にある「出力形式」系の設定を参考にし、Web版DrawLabへ最小変更で取り込むための追加要件を定義する。

本要件は、トーナメント生成ロジックではなく、生成済みドローの表示・印刷レイアウトを対象とする。

## 2. 前提

- 既存のシード配置、BYE配置、選手配置順序の生成ロジックは変更しない。
- 生成済み `GeneratedDraw.slots` の並び順・対戦構造は、出力形式オプションによって変えない。
- Excel VBAコードやExcelセル結合、Excel罫線の実装は移植しない。
- Web版ではSVG/HTMLレンダラーと印刷CSSで表現する。
- 既存の `DrawOptions` は生成オプションとして扱い、出力形式は別責務のオプションとして分離する。

## 3. Excelマクロ仕様から読み取った対象

Excelマクロでは、出力・表示に関係する主な設定として以下が存在する。

| 項目 | マクロ上の意味 | Web版での扱い |
|---|---|---|
| トーナメント出力形式 | 片山出力 / 両山出力 | 最小対応対象 |
| 右山のドロー番号位置 | 両山出力時の右山側の番号位置 | 最小対応対象 |
| シード番号位置 | シード番号をトーナメント表の外側または内側へ配置 | 最小対応対象 |
| ドロー線の種類 | 1: 細線 / 2: 標準線 / 3: 太線 / 4: 極太線 | 最小対応対象 |
| チーム名のカッコ | 所属チーム名をカッコ付きで表示 | 最小対応対象 |
| 選手名・チーム名の文字横位置 | 標準 / 中央 / 均等割付 | 最小対応対象 |
| 選手名・チーム名の横幅フィット | 列幅自動調整 | Webでは直接移植せず、表示崩れ防止要件として扱う |
| グリッド罫線 | Excelのグリッド線表示 | Web版では対象外 |
| チーム名変換 | 全角/半角等の文字種変換 | 生成ロジックへ影響し得るため最小対応対象外 |
| 出力ページ数 | 両山出力時のExcel改ページ制御 | Web版ではA4縦の印刷ページ分割として対応 |

## 4. 対象スコープ

## 4.1 対象

最小変更では、以下を実装対象とする。

- 出力形式オプションの型定義追加
- オプション設定画面の「構成概要」パネルを削除し、同じ位置を「出力形式」設定パネルに置換
- Tournament保存データへの出力形式オプション保存
- 大会情報保存/読込での出力形式オプション保持
- プレビュー画面での出力形式オプション反映
- 印刷時に同じレイアウト設定を反映
- 出力ページ数に応じた印刷用SVG分割

## 4.2 対象外

最小変更では、以下は実装しない。

- 生成ロジックの変更
- シード/BYE/選手配置結果の変更
- Excelのセル結合・列幅計算の再現
- Excelグリッド線表示
- チーム名の文字種変換
- Excelファイル出力

## 5. データ要件

## 5.1 追加型

`DrawOptions` とは別に、表示・印刷専用の型を追加する。

```ts
type DrawOutputOptions = {
  bracketLayout: "singleSide" | "bothSides";
  outputPageCount: 1 | 2 | 4 | 8 | 16 | 32;
  rightSideDrawNumberPosition: "left" | "right";
  seedNumberPosition: "outer" | "inner";
  lineWeight: "thin" | "normal" | "bold" | "extraBold";
  teamNameBrackets: boolean;
  textAlign: "default" | "center" | "distributed";
};
```

## 5.2 Tournamentへの追加

`Tournament` に任意項目として追加する。

```ts
type Tournament = {
  // existing fields
  outputOptions?: DrawOutputOptions;
};
```

既存保存データとの互換性を保つため、`outputOptions` が存在しない場合はデフォルト値を補完する。

## 5.3 デフォルト値

```ts
const DEFAULT_DRAW_OUTPUT_OPTIONS: DrawOutputOptions = {
  bracketLayout: "singleSide",
  outputPageCount: 1,
  rightSideDrawNumberPosition: "right",
  seedNumberPosition: "outer",
  lineWeight: "normal",
  teamNameBrackets: false,
  textAlign: "default",
};
```

## 6. 画面要件

## 6.1 オプション設定画面

オプション設定画面の既存「構成概要」パネルは削除し、その表示領域を「出力形式」パネルに置き換える。既存の「シード位置・BYE位置」「選手配置順序」の設定は維持する。

「構成概要」に表示していた有効参加者数、ドローサイズ、BYE数、シード指定数は、基本情報画面・名簿入力画面などの情報と重複するため、オプション設定画面では表示しない。これは表示上の変更であり、生成処理・検証処理・保存データの扱いには影響しない。

| 項目 | UI | 初期値 | 補足 |
|---|---|---|---|
| 出力形式 | radio | 片山 | 片山 / 両山 |
| 出力ページ数 | select | 1ページ | 両山の場合のみ有効。ドローサイズに応じて1 / 2 / 4 / 8 / 16 / 32を表示 |
| 右山のドロー番号位置 | radio | 右 | 出力形式が両山の場合のみ有効 |
| シード番号位置 | radio | 外側 | 外側 / 内側 |
| ドロー線の太さ | select または segmented control | 標準 | 細線 / 標準線 / 太線 / 極太線 |
| チーム名をカッコ付きで表示 | checkbox | OFF | 所属チーム表示のみ変更 |
| 文字位置 | radio | 標準 | 標準 / 中央 / 均等割付 |

## 6.2 無効状態

- 出力形式が片山の場合、右山のドロー番号位置は無効表示にする。
- 出力形式が片山の場合、出力ページ数は1ページとして無効表示にする。
- 無効表示時も保存値は保持してよい。
- 片山から両山へ戻した場合、以前の右山ドロー番号位置が復元されること。

## 6.3 文言

- 画面上では「Excel」「JSON」など一般利用者に馴染みづらい内部用語は使わない。
- 「出力形式」「片山」「両山」「ドロー線の太さ」など利用者が印刷結果を想像しやすい文言にする。

## 7. 描画要件

## 7.1 共通

- 出力形式オプションは、生成済みドローの表示方法だけを変更する。
- 表示切替によって再抽選・再生成は行わない。
- 表示切替後も、同じ `GeneratedDraw.slots` を参照する。

## 7.2 片山

- 現在のプレビュー表示を基本とする。
- 既存のトーナメント線、選手ボックス、シード表示、BYE表示の構造を維持する。

## 7.3 両山

- ドローの前半を左山、後半を右山として表示する。
- 左山・右山ともに、ドロー番号を上から昇順で表示する。
- 決勝に向かって左右から中央へ進む構成にする。
- 右山の選手ボックスは、右山のドロー番号位置設定に従って番号列の位置を変える。
- 両山表示でも、スロット番号・シード番号・選手名・所属チーム・BYEが判別できること。

## 7.4 シード番号位置

- `outer` の場合、シード表示をトーナメント表の外側に表示する。
- `inner` の場合、シード表示をトーナメント表の内側に表示する。
- 片山表示では、外側を左側、内側を右側として扱う。
- 両山表示では、左山の外側を左側・内側を右側、右山の外側を右側・内側を左側として扱う。
- 旧データの `left` は `outer`、`right` は `inner` に変換して読み込む。
- シードなしの行とシードありの行で、選手名の開始位置が不自然にずれないこと。

## 7.5 ドロー線の太さ

SVGレンダラーでは、以下を目安に線幅へ変換する。

| 設定 | strokeWidth目安 |
|---|---:|
| 細線 | 1 |
| 標準線 | 2 |
| 太線 | 3 |
| 極太線 | 4 |

## 7.6 チーム名カッコ表示

- `teamNameBrackets` がONの場合、所属チーム名をカッコ付きで表示する。
- 所属チームが未入力の場合、カッコだけを表示しない。
- ダブルスで所属チーム1・2を表示する場合、それぞれに適用する。

## 7.7 文字位置

- `default` は現行表示に準拠する。
- `center` は選手名・所属チームを中央寄せにする。
- `distributed` は選手名・所属チームを表示領域の左端から均等割付する。
- 表示領域は、出場者ボックス内のドロー番号・シード番号を除いた範囲とする。
- 出場者ボックスは、左右端からドロー番号領域、シード番号領域、文字領域の順に動的に割り当てる。固定座標の空き領域は設けない。
- シード指定が1件もないドローでは、シード番号領域を予約せず、文字領域として使用する。
- 出場者ボックス幅は、選手名・所属チーム・シード有無から算出し、全カードで同一幅とする。カードごとの幅変更は行わない。
- シード番号を右側に配置する場合は、左側のシード用余白を設けず、全行の選手名・所属チームを左側へ寄せる。右端はシード番号の手前で揃える。
- シード番号を左側に配置する場合は、ドロー番号とシードバッジの間隔、およびシードバッジと選手名の間隔を確保したうえで、左端の余白を抑える。
- 両山の右山でドロー番号を右側に配置する場合は、ドロー番号の手前に表示余白を確保し、選手名・所属チームと重ならないようにする。
- 各段の接続線の横幅は、1回戦の出場者カード端から最初の縦線までの横線と同じ長さにする。両山の中央では「優勝」カードを表示せず、左右の最終線を同じ長さで接続し、中央から上へ線を出す逆T字とする。
- 文字間に追加する余白は、1文字分の幅を上限とする。短い文字列はこの上限まで広げ、上限を超えて広がる場合は表示領域の幅で止める。
- 表示領域に収まらない長い文字列は文字幅を縮小してボックス内に収め、他の要素と重ならないようにする。
- SVGの `textLength` と `lengthAdjust` を使用し、選手名・所属チームの行ごとに適用する。

## 7.8 ダブルス表示

- ダブルスの選手名1・選手名2は、出場者ボックス内で縦並びに表示する。
- 選手名1・選手名2に対応する所属チーム1・所属チーム2は、選手名の右側に表示する。
- 選手名列・所属チーム列は、表示対象の実文字幅から列幅を算出し、左右の山で同じフォントサイズと列幅を使用する。
- `sameTeam` が有効な場合は、同じチーム名を2行に重複表示せず、選手名2行の中央に1回表示する。
- 所属チームが未入力の場合は、チーム名を表示しない。
- 地区はトーナメント表に表示しない。地区は配置ロジックの偏り回避にのみ使用する。

## 7.9 途中対戦カード

- `勝者 M1-1`、`勝者 M2-1` などの途中ラウンドの対戦カードは表示しない。
- 途中カードを非表示にしても、ラウンド間のコネクタは連続して表示する。
- 上部のラウンド見出しは表示しない。
- 「優勝」カードは表示しない。両山の中央は逆T字のトーナメント線で接続する。
- 非表示にした途中カードの矩形幅は、トーナメント表全体の横幅計算に含めない。
- 出場者カード幅、ラウンド間隔、決勝周辺の余白は、不要な空白が過大にならない値とする。

## 7.10 PDF出力ページ数

- 用紙はA4縦、余白は上下左右10mmを基本とする。
- 両山では1、2、4、8、16、32ページから、1ページあたり4ドロー以上となる範囲を選択できるようにする。
- 生成済みスロットを連続するドロー番号の範囲でページ数分に分け、各ページを独立した両山として再描画する。
- 32ドローを2ページで出力する場合、1ページ目は左山1～8・右山9～16、2ページ目は左山17～24・右山25～32とする。
- ページ間を接続するトーナメント線は描画しない。
- 各ページのSVGは縦横比を維持して印刷可能領域内へ縮小配置する。
- 画面プレビューは、出力ページ数に合わせたA4縦の用紙を縦に並べ、印刷時と同じページ内容を表示する。
- 各ページに大会情報を表示し、ページ番号 / 総ページ数はフッター中央に表示する。
- 片山は1ページ出力とし、ページ数の選択を無効にする。
- ブラウザ印刷側で用紙、余白、倍率、ヘッダー・フッターを変更した場合は、指定ページ数を保証せず、可能な限り指定ページ数へ収める。

## 8. 保存・読込要件

- ローカル保存に `outputOptions` を含める。
- 大会情報保存に `outputOptions` を含める。
- 大会情報読込時、`outputOptions` がない旧データはデフォルト値を補完する。
- 不正値が含まれる場合は、項目ごとにデフォルト値へ補正する。
- 出力形式オプションだけを変更した場合、生成済み状態は維持する。

## 9. バリデーション要件

- 出力形式オプションは選択式のため、通常はユーザー入力エラーを表示しない。
- 読込データに不正値がある場合は、エラーではなくデフォルト補正する。
- 補正によって生成済みドローを破棄しない。

## 10. 受け入れ条件

- 片山/両山を切り替えても、生成済みドローのスロット配置が変わらないこと。
- 片山/両山を切り替えても、再生成確認や警告確認が表示されないこと。
- 両山表示で左右の山が中央の決勝へ接続されること。
- 右山のドロー番号位置を切り替えると、右山側の番号位置だけが変わること。
- シード番号位置を切り替えると、各山の外側・内側に応じてシード表示位置が変わること。
- ドロー線の太さを切り替えると、トーナメント線の太さが変わること。
- チーム名カッコ表示をONにすると、所属チーム名だけがカッコ付きになること。
- ダブルスで選手名が縦並びになり、対応するチーム名が右側に表示されること。
- 地区がトーナメント表に表示されないこと。
- 上部のラウンド見出し、途中の「勝者 M…」カード、「優勝」カードが表示されず、両山の中央が逆T字のコネクタで接続されること。
- A4縦のブラウザ印刷で、選択したページ数と同じページ数のPDFを出力できること。
- 大会情報保存/読込後も出力形式オプションが復元されること。
- 旧データを読み込んでもプレビュー画面が表示できること。

## 11. テスト観点

## 11.1 機能観点

- 出力形式の設定値が保存・復元されること。
- プレビュー表示に設定値が反映されること。
- 印刷時も同じ表示設定が反映されること。
- 指定ページ数に応じて、連続するドロー番号の範囲ごとに独立した印刷用SVGが生成されること。
- 出力形式変更が生成済み状態を未生成にしないこと。

## 11.2 非機能観点

- 64ドロー程度でも表示が極端に重くならないこと。
- 印刷時に操作パネルやサイドバーが混入しないこと。
- 各印刷ページでトーナメント表がA4縦の印刷可能領域から見切れないこと。
- 画面幅が狭い場合でも主要情報が重ならないこと。

## 11.3 データ観点

- `outputOptions` が存在しない旧データを読み込めること。
- 各項目に不正値がある場合、項目単位でデフォルト補正されること。
- 大会情報保存/読込で `outputOptions` が欠落しないこと。

## 11.4 UI観点

- 片山選択時、右山のドロー番号位置が無効であることが分かること。
- 片山選択時、出力ページ数が1ページで無効表示されること。
- 無効状態の項目が誤操作できないこと。
- シードあり/なしで選手名の位置が不自然にずれないこと。
- 文字がボックス内で重ならないこと。

## 12. テストケース概要

## 12.1 正常系

| ケース | 意図 |
|---|---|
| 片山でプレビュー表示する | 既存表示との互換性を確認する |
| 両山でプレビュー表示する | 左右山構成が成立することを確認する |
| 右山番号位置を切り替える | 両山固有オプションの反映を確認する |
| ダブルスでプレビュー表示する | 選手名の縦並びとチーム名の右側配置を確認する |
| 地区を入力した状態でプレビュー表示する | 地区が表示されず、配置ロジックだけに使用されることを確認する |
| 中間カードを含むドローをプレビュー表示する | 勝者カードがなく、コネクタが連続することを確認する |
| 大会情報保存/読込を行う | 出力形式オプションの永続化を確認する |

## 12.2 異常系

| ケース | 意図 |
|---|---|
| 不正な `bracketLayout` を含むデータを読み込む | デフォルト補正で復旧できることを確認する |
| 不正な `lineWeight` を含むデータを読み込む | 項目単位の補正を確認する |

## 12.3 境界値

| ケース | 意図 |
|---|---|
| 4ドローで両山表示する | 最小ドローで左右分割が破綻しないことを確認する |
| 64ドローで両山表示する | 大きいドローで表示・印刷が破綻しないことを確認する |

## 12.4 状態遷移

| ケース | 意図 |
|---|---|
| 生成後に出力形式だけ変更する | 生成済み状態が維持されることを確認する |
| 片山から両山へ変更し、再度片山へ戻す | 無効項目の保存値保持と復元を確認する |
| 旧データ読込後にプレビューへ遷移する | 後方互換性を確認する |

## 13. 実装上の注意

- `DrawOutputOptions` はレンダラー層へ渡し、ドメイン生成関数の引数には追加しない。
- `GeneratedDraw` には出力形式オプションを含めない。生成結果と表示設定を分離する。
- `outputOptions` 変更時に `generatedDraw` を破棄しない。
- 既存の `DrawOptions` へ表示専用項目を混在させない。
- 両山表示はSVG/HTMLレンダラー側の責務とし、スロット配列の並べ替え結果を保存しない。

## 14. 未決事項

- 両山表示時の決勝周辺の具体的な余白・座標設計。
- 128ドロー以上を将来対象にする場合の印刷縮尺。
- 出力形式の変更操作をプレビュー画面にも簡易配置するかは、今回の対象外とする。
